# Checklist — antes de postar

- [ ] `python3 ferramentas/gancho_check.py exemplos/<slug>` → OK.
- [ ] Storyboard aprovado pelo diretor (gancho escolhido comparando de dois em dois).
- [ ] `npx hyperframes check` → 0 erros.
- [ ] `ffprobe renders/<slug>.mp4` → 1080x1920, 25–60 s, com áudio.
- [ ] Quadro 0 (`ffmpeg -i renders/<slug>.mp4 -frames:v 1 q0.jpg`): a coisa do gancho grande e o texto que a nomeia.
- [ ] Assistiu uma vez com som e uma sem som: a legenda conta sozinha?
- [ ] Nada importante na faixa de baixo nem na da direita (botões da rede).
- [ ] Números da tela = voz = `fatos.md`.
- [ ] `pie.txt`: 1ª linha engancha; sem hashtag; link etiquetado na bio (`agentes/link.py --onde bio`).
- [ ] Postar à mão, pelo celular.
- [ ] Cada reel ensina uma coisa nova: o formato repete, o assunto e a pesquisa não.
